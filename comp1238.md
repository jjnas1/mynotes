## Week 1 - History
- One writing system can be used by many languages.
- Cuneiform looks weird but was an early development in structured communication.

## Week 2 - Bits and Bytes
- Computers operate using binary code consisting entirely of 1s and 0s.
- A standard kilobyte traditionally translates to 1024 bytes in computer memory tracking.

## Week 3 - Text Structure
- Markup languages got their name from traditional paper manuscript editing systems.
- Markdown is a lightweight syntax used to format clean text directly into HTML layouts.

## Week 4 - Keyboards and Editors
- Text editors like VS Code handle raw text formatting seamlessly for system control files.
- Word processors like Microsoft Word are specialized for styled document design layouts.

## Week 5 - CLI
- The command line interface lets developers run complex file systems faster than a GUI.
- Terminal commands like 'ls' reveal directory details, while 'cat' displays file contents.
